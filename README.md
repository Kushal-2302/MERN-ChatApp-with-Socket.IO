# QuickChat 💬

QuickChat is a real-time chat application built using the MERN Stack and Socket.IO. It allows users to register, log in securely, and exchange messages instantly in a responsive chat interface.

## 🚀 Live Demo

https://chat-app-chi-lime.vercel.app/login

## 📂 GitHub Repository

https://github.com/Kushal-2302/MERN-ChatApp-with-Socket.IO

## ✨ Features

- User Authentication (JWT)
- Real-Time Messaging with Socket.IO
- Secure Password Hashing
- Responsive UI
- Persistent Chat Storage
- User Search Functionality

## 🛠️ Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Socket.IO
- JWT
- bcrypt.js

## ⚙️ Installation

```bash
git clone https://github.com/Kushal-2302/MERN-ChatApp-with-Socket.IO.git
cd quickchat
npm install
```
